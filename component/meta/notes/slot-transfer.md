# Перенос компонента между слотами

Готовый компонент является настоящим Element либо DOMGroup. Передача этого же
объекта в `content` другой области одного Document перемещает существующие
Nodes без клонирования. Общие DOM placement и lifecycle сохраняют identity,
state, focus, listeners и effects при same-Document переносе. Прежний владелец
области не удаляет переданные другому владельцу Nodes при cleanup.

Это проверяют `tests/dom-content.test.ts` и `slot/test/composition.test.ts`.
Распределение авторского содержимого принадлежит
[Slot в JSX](../../../jsx/slot/plan/meta/notes/design.md).

Новый construction record с теми же constructor/key в другой области не
означает передачу уже существующего объекта. Generated keyed map принадлежит
конкретной области; общего поиска экземпляров между областями нет. Такое
перераспределение authored records с сохранением state остаётся отдельным
неподтверждённым контрактом. Переменное имя JSX slot не поддерживается.

Для расширения этого контракта нужны проверки переноса A → B, context,
конфликтов ключей, нескольких корней и отказа native вставки. Переименование
области и повторное создание компонента не доказывают сохранение identity.
