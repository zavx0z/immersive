# Перенос компонента между слотами

Отложенная возможность Component: перенос смонтированного компонента между
именованными областями одного получателя в том же Document с сохранением
DOM identity, state, focus, refs, listeners и effects.
Распределение авторского содержимого принадлежит
[Slot в JSX](../../../jsx/slot/plan/meta/notes/design.md).

## Текущее ограничение

В [runtime](../../src/runtime.ts) `prepareSingleRange` ищет существующий экземпляр
только в `binding.child`, `prepareKeyedRange` — в `binding.childrenByKey`.
Одинаковые template/key в разных областях не связывают экземпляры.
При смене области создаётся новый экземпляр, прежний размонтируется;
state теряется, effects и refs проходят завершение и повторную установку.

`moveInstanceRegionBefore` уже перемещает существующий DOM-диапазон при
перестановке внутри keyed-области. Это внутренняя механика, а не готовый
контракт переноса между областями. Само распределение детей в JSX
не добавляет runtime поиск экземпляра в другой области.

## Где продолжать

Реализация принадлежит композиции Component: подготовке областей в
`prepareSingleRange` и `prepareKeyedRange`, принятию изменений и перемещению
диапазонов в `applyRangeDom` и `moveInstanceRegionBefore`.
Нужно определить общую область identity и разрешение конфликтов ключей,
перенос владения экземпляром, prepare/commit/rollback и обновление context.
Частично применённый перенос не должен оставлять два экземпляра или терять один.

Проверки будущего контракта:

- Перенос A → B сохраняет тот же Element, hook state, focus, refs и listeners.
- Effects не завершаются и не создаются заново только из-за смены области.
- Context следует согласованному дереву получателя без устаревших значений.
- У нескольких корневых узлов перемещается весь диапазон того же экземпляра.
- Окончательный unmount выполняет cleanup ровно один раз.
- Ошибка подготовки оставляет ранее принятое дерево и его ресурсы действующими.

До реализации переменное имя слота нельзя выдавать за поддерживаемый перенос
с сохранением состояния. Проверка потери state не заменяет требуемый контракт.
