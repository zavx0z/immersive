# ViewPoint

`<viewpoint>` — базовая камера одного Space. Класс `ViewPointElement`
экспортируется из `@zavx0z/immersive-dom/viewpoint` и доступен без регистрации фабрик.
Элемент не создаёт Renderer, Canvas, подписки или отдельный цикл кадров.

## Текущий API

Режим navigation задаётся явно и не создаёт дополнительную камеру.

| Свойства | Значение и единицы |
| --- | --- |
| `x`, `y`, `z` | Положение в мм, по умолчанию `10`, `-10`, `10` |
| `targetX`, `targetY`, `targetZ` | Цель в мм, по умолчанию нули |
| `fov` | Угол обзора в радианах, по умолчанию `1` |
| `near`, `far` | Плоскости отсечения в мм, по умолчанию `0.1` и `1000` |
| `controls` | Разрешение управления камерой, по умолчанию `false` |
| `navigation` | `orbit` по умолчанию либо `fly` для прохода через слои |
| `flySpeed` | Скорость fly в мм на единицу zoom delta, по умолчанию `10` |

Мировая ось вверх — Z. Числовые свойства отражаются в атрибутах; для цели
используются `target-x`, `target-y`, `target-z`. ViewPoint не принимает детей.
Повторный render с теми же авторскими значениями сохраняет изменения камеры,
выполненные командами или жестами.

`saveState()` запоминает обзор. `reset()` восстанавливает его одной транзакцией
без изменения `controls`; возвращает `false`, если обзор ещё не сохранён.
`dollyTo(distance, target?)` меняет расстояние до цели, сохраняя направление.
Недопустимая команда отклоняется до изменения камеры.

Тесты находятся в `tests`; зависимости тестов импортируются относительными
путями. Запуск: `bun test dom/viewpoint/tests`. Названия и сообщения `expect` — на русском.


В режиме `fly` Browser переводит pinch/zoom в поступательное перемещение eye и
его target вдоль cursor ray; движение продолжается через прежний target и уровни
сцены. `flySpeed` отражается в `fly-speed`, должен быть конечным и положительным.
Navigation и скорость остаются конфигурацией приложения; saveState/reset их
не заменяют. Orbit по умолчанию сохраняет прежнее поведение.
