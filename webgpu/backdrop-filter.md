# Размытие фона UI

Renderer передаёт отдельный backdrop record перед фоном и содержимым элемента.
WebGPU сохраняет его место в paint order. В этом месте текущий target уже содержит
предыдущие панели; следующее окно видит их фон, рамки, текст и другие потомки.
Собственный foreground фильтруемой панели рисуется после размытия.

Backend сохраняет обычный scalar RoundedRect Mesh с производными параметрами
операции. Он разделяет instanced runs. Геометрия, clipping и shape mask остаются
общими с обычным прямоугольником; собственного semantic tree нет.

## Проходы и ресурсы

Перед первой операцией UI-фон рисуется в том же проходе, что и предыдущая сцена.
Перед последующими операциями заканчивается текущий UI pass. Полноразмерного
snapshot и копирования перед каждой панелью нет: compute читает MSAA color
между проходами. UI сохраняет MSAA target между операциями, resolve выполняется
после последнего фильтра.

Compute area prefilter усредняет все исходные texels и MSAA samples, покрытые
каждым уменьшенным texel. Поэтому тонкие линии не пропускаются при уменьшении
и не превращаются в полосы. На один результат работают 1/4/16/32 lanes для
масштабов 1, 1/2, 1/4 и 1/8; reduction использует workgroup memory. MSAA выборки
развёрнуты, depth weights вычисляются без разветвления по foreground.

Для World каждая исходная выборка проверяется относительно плоскости Display.
RGBA и независимая validity сворачиваются вместе; нормализация происходит
после вертикальной оси. Прозрачность не используется как признак допустимости.
HUD принимает все выборки фона. Затем H/V применяют плотный Gaussian на уменьшенной
сетке с объединением соседних bilinear весов. Дисперсия area box учитывается
при выборе Gaussian sigma, а ROI включает полный halo обеих осей и округление.

Таким образом cold операция имеет один compute и два render passes. Повтор
готового результата не запускает ни один из них. Scratch занимает 30 bytes на
уменьшенный pixel: RGBA16float area/validity, H color/validity и общий V fallback.
Все sampled texels предварительно записываются в ROI; полноразмерные intermediate
textures не добавляются.

Финальный RoundedRect shader смешивает размытый premultiplied RGBA с текущим
attachment по rounded/clip/opacity mask. При доступной optional feature
`dual-source-blending` достаточно одного draw; иначе два draw в одном pass
раздельно сохраняют RGB и alpha. Обе ветви проходят native pixel tests.
Прозрачный фон не складывается сам с собой. UI continuation использует read-only
attachments там, где pipeline не пишет depth/stencil; текст сохраняет stencil write.

Горизонтальная scratch texture общая для операций target. Результаты вертикальной
оси сохраняются по операции с общим лимитом 32 MiB на Renderer. При исчерпании
лимита фильтр использует общий scratch без reuse. Размер и shader-сетка не
ухудшаются ради попадания в бюджет. Для Canvas ключом служит Canvas, а не
меняющийся swapchain texture object. Разные операции одного command buffer
получают независимые uniform slots. Resize, удаление Display, исчезновение
операций и dispose освобождают ресурсы; неуспешные частичные выделения откатываются.

## Повторное использование

Подготовленные входы сравниваются точно: значения uniforms и clip records,
порядок draw, geometry versions, текст, изображения и параметры камеры/света.
Для общего instanced storage сравниваются только records и palette slots,
которые читает данный draw. Подписи не используют вероятностный hash.

Каждая операция сравнивает отрезок paint order после предыдущего фильтра.
Изменение раннего отрезка запрещает reuse всех следующих фильтров этого кадра.
Изменение текста/заливки после последнего фильтра не запускает Gaussian заново.
Соседние готовые результаты смешиваются в одном UI pass. Если он был открыт
без resolve до последнего blur, отдельный пустой pass выполняет только финальный
resolve; повторного рисования сцены в нём нет.
Сигнатуры и GPU outputs подтверждаются только после submission; прерванная
запись команд не делает незаписанный output валидным. Камера, внешняя сцена,
ранний UI, clipping или sigma возвращают расчёт нужных операций.

Если все поддержанные входы кадра неизменны, Renderer копирует сохранённый
готовый кадр в текущую presentation texture без render passes. Это не отменяет
необходимость demand lifecycle: вызов всё ещё подготавливает и сравнивает входы.
Видео, ожидающие изображения и неизвестные material/attribute implementations
не получают право на reuse. Замена bitmap внутри прежней GPU texture учитывается
через content epoch. Часть общих параметров слоёв сравнивается консервативно:
лишний пересчёт допустим, устаревшее изображение — нет.

Без положительного blur сохраняются обычные проходы и render bundles;
промежуточных blur textures нет. Pipeline после первого использования может
сохраняться до dispose, чтобы повторное включение не компилировало shader заново.

## Границы реализации

Поддерживается один CSS blur в px, включая нулевое значение, и none.
Это экранное приближение: sigma масштабируется по проекции в центре панели;
при неодинаковом масштабе осей выбирается большая ось. Точный анизотропный или
перспективно меняющийся kernel здесь не реализован.

Backdrop Display получает общий кадр, включая внешнюю сцену за поверхностью.
При положительном blur его содержимое рисуется непосредственно в общий target:
изолированная растровая матрица не содержит нужного фона. Обычные Display,
none, blur(0) и скрытый фильтр сохраняют прежний выбор по плотности пикселей.
Физические размеры, DOM и граф содержимого не меняются; при blur UI рисуется
в разрешении Canvas, а не увеличенными пикселями номинальной матрицы Display.

Prefilter проверяет глубину сцены относительно плоскости Display для каждого MSAA sample.
Более близкие непрозрачные объекты не входят в выборки, оставшиеся веса
нормализуются после двух осей фильтра. Финальный depth test сохраняет передний план резким, а отсечение
выборок предотвращает цветной ореол с его краёв. HUD использует весь видимый фон
без этой отсечки: сцена целиком расположена за HUD. Это экранный эффект;
скрытые сценой пиксели не восстанавливаются дополнительной трассировкой.
Независимая изоляция CSS backdrop roots, групповой opacity, списки фильтров и
изменение containing block не входят в текущий контракт Renderer.

Эффект требует полупрозрачного фона: непрозрачная заливка после фильтра закроет
его результат. UI-компонент задаёт обычный CSS; WebGPU не различает Window,
панель или конкретное приложение.

## Свидетельства

- `renderer/html/tests/backdrop-filter.test.ts`: каскад, paint order, clipping,
  scroll и transform.
- `webgpu/tests/backdrop-backend.test.ts`: retained Mesh и instancing barriers.
- `webgpu/tests/backdrop-filter.test.ts`: ресурсы, swapchain, partial failure,
  ROI, uniform slots и перевод CSS sigma в физические пиксели.
- `webgpu/tests/backdrop-blur.native.test.ts`: настоящие пиксели HUD и Display разной плотности, включая premultiplied alpha.
- `webgpu/tests/backdrop-scene.native.test.ts`: геометрия World за Display,
  резкий передний план без цветного halo, изменяющийся фон и сохранение содержимого.
- `webgpu/tests/backdrop-display-mode.test.ts`: реальный выбор общего прохода
  при blur и возврат к выбору растрового режима при none/zero/hidden.
- `webgpu/tests/backdrop-prefix-cache.native.test.ts`: изменяющийся UI и сцена;
  каждое состояние сравнивается с новым Renderer с пустым cache.
- `webgpu/tests/frame-replay.native.test.ts`: полное повторение кадра, изображения
  с неизменной GPU texture identity, свет, камера, геометрия и текст.
- `webgpu/tests/backdrop-output-cache.test.ts`: бюджет, abort, resize, ownership
  и ошибки частичного выделения ресурсов.
- Window, сценарий «Матовое стекло»: обычная авторская CSS-композиция.

`bun headless/fixtures/backdrop-performance.ts --motion all` измеряет синтетический UI с
нулём, одним и тремя перекрывающимися фильтрами. Каждая панель занимает половину
ширины и половину высоты Canvas. Измеряется renderComposition вместе с ожиданием
GPU через 1px copy/map; это не чистое GPU-время и не FPS рабочего приложения.
