# Размытие фона UI

Renderer передаёт отдельный backdrop record перед фоном и содержимым элемента.
WebGPU сохраняет его место в paint order. В этом месте текущий target уже содержит
предыдущие панели; следующее окно видит их фон, рамки, текст и другие потомки.
Собственный foreground фильтруемой панели рисуется после размытия.

Backend сохраняет обычный scalar RoundedRect Mesh с производными параметрами
операции. Он разделяет instanced runs. Геометрия, clipping и shape mask остаются
общими с обычным прямоугольником; собственного semantic tree нет.

## Проходы и ресурсы

Перед первой операцией UI-фон рисуется в том же проходе, что и предыдущая сцена.
Перед последующими операциями заканчивается текущий UI pass. Снимок target
копируется в отдельную texture; фильтр не читает свой render attachment.
Копирование ограничивается экранной областью панели с halo в 3 sigma.

Фильтр приближает Gaussian двумя проходами по 19 выборок на ось.
HUD использует bilinear выборки; World читает точные texels, прошедшие проверку
глубины, чтобы соседний texel переднего плана не смешивался с разрешённой выборкой.
Масштаб промежуточного изображения выбирается по физическому sigma: 1, 1/2,
1/4 или 1/8. Scissor ограничивает горизонтальный проход областью с вертикальным
halo, вертикальный — областью панели. Финальный RoundedRect shader смешивает
исходный и размытый premultiplied RGBA по rounded/clip/opacity mask и заменяет
соответствующий цвет. Поэтому прозрачный фон не складывается сам с собой.

Один snapshot и scratch textures переиспользуются всеми окнами данного target.
Для Canvas ключом служит Canvas, а не меняющийся swapchain texture object.
Разные операции одного command buffer получают независимые uniform slots.
Удаление Display, resize, переход к отсутствию blur и dispose освобождают ресурсы;
неуспешное частичное выделение также освобождает уже созданные scratch textures.

Без положительного blur сохраняются обычные проходы и render bundles;
промежуточных blur textures нет. Pipeline после первого использования может
сохраняться до dispose, чтобы повторное включение не компилировало shader заново.
Результат фильтра между изменившимися кадрами не кешируется: это исключает
устаревший фон при движении камеры, видео или анимации. Demand lifecycle приложения
сам решает, нужен ли новый кадр неподвижной сцене.

## Границы реализации

Поддерживается один CSS blur в px, включая нулевое значение, и none.
Это экранное приближение: sigma масштабируется по проекции в центре панели;
при неодинаковом масштабе осей выбирается большая ось. Точный анизотропный или
перспективно меняющийся kernel здесь не реализован.

Backdrop Display получает общий кадр, включая внешнюю сцену за поверхностью.
При положительном blur его содержимое рисуется непосредственно в общий target:
изолированная растровая матрица не содержит нужного фона. Обычные Display,
none, blur(0) и скрытый фильтр сохраняют прежний выбор по плотности пикселей.
Физические размеры, DOM и граф содержимого не меняются; при blur UI рисуется
в разрешении Canvas, а не увеличенными пикселями номинальной матрицы Display.

Обе оси фильтра проверяют глубину сцены относительно плоскости Display.
Более близкие непрозрачные объекты не входят в выборки, оставшиеся веса
нормализуются. Финальный depth test сохраняет передний план резким, а отсечение
выборок предотвращает цветной ореол с его краёв. HUD использует весь видимый фон
без этой отсечки: сцена целиком расположена за HUD. Это экранный эффект;
скрытые сценой пиксели не восстанавливаются дополнительной трассировкой.
Независимая изоляция CSS backdrop roots, групповой opacity, списки фильтров и
изменение containing block не входят в текущий контракт Renderer.

Эффект требует полупрозрачного фона: непрозрачная заливка после фильтра закроет
его результат. UI-компонент задаёт обычный CSS; WebGPU не различает Window,
панель или конкретное приложение.

## Свидетельства

- `renderer/html/tests/backdrop-filter.test.ts`: каскад, paint order, clipping,
  scroll и transform.
- `webgpu/tests/backdrop-backend.test.ts`: retained Mesh и instancing barriers.
- `webgpu/tests/backdrop-filter.test.ts`: ресурсы, swapchain, partial failure,
  ROI, uniform slots и перевод CSS sigma в физические пиксели.
- `webgpu/tests/backdrop-blur.native.test.ts`: настоящие пиксели HUD и Display разной плотности, включая premultiplied alpha.
- `webgpu/tests/backdrop-scene.native.test.ts`: геометрия World за Display,
  резкий передний план без цветного halo, изменяющийся фон и сохранение содержимого.
- `webgpu/tests/backdrop-display-mode.test.ts`: реальный выбор общего прохода
  при blur и возврат к выбору растрового режима при none/zero/hidden.
- Window, сценарий «Матовое стекло»: обычная авторская CSS-композиция.

`bun headless/fixtures/backdrop-blur.ts benchmark` измеряет синтетический UI с
нулём, одним и тремя перекрывающимися фильтрами. Каждая панель занимает половину
ширины и половину высоты Canvas. Измеряется renderComposition вместе с ожиданием
GPU через 1px copy/map; это не чистое GPU-время и не FPS рабочего приложения.

[Замер Intel HD 630](meta/research/2026-10-09/backdrop-performance.json) сохраняет
исходные выборки, медианы, параметры сцены и ограничения измерения.
