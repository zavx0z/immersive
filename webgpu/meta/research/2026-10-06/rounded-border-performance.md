# Проверка производительности разноцветных рамок

Новая возможность проверена 6 октября 2026 на Intel HD Graphics 630, Metal.
Обычная рамка сохраняет 128-байтовую instanced-запись, один quad и прежние
пакеты рисования. Pipeline с override `perSideBorderColors: 0` исключает
ветку независимых цветов. Дополнительный Float32 buffer выделяется лениво.
Одна изменённая разноцветная рамка обновляет 64 байта палитры; порядок слотов
и число команд не меняются. После удаления последнего цветного экземпляра
возвращается одноцветный pipeline; буфер сохраняется для повторного использования. Scalar uniform сохраняет размер 256 байт.

## Нативный GPU

Один device и одинаковые buffers, 2048 неперекрывающихся одноцветных рамок,
2304 × 1152, 4× MSAA, один draw на кадр. После 5 прогревов — 20 парных
измерений по 4 кадра с чередованием старого и нового WGSL. Время получено
через настоящий `timestamp-query`. Старый WGSL прочитан из Git HEAD до
изменений; SHA-256 обоих текстов сохранены в JSON.

| Метрика | До | После |
| --- | ---: | ---: |
| GPU median, мс | 3.19488 | 3.19488 |
| GPU p95, мс | 3.325952 | 3.489792 |
| Steady GPU buffer allocations | 0 | 0 |
| Steady uploads | 0 | 0 |
| Draws / frame | 1 | 1 |

Медиана парного отношения после/до — 1.005208. Разброс сохраняется:
это результат конкретной нагрузки и устройства, а не гарантия одинакового
времени каждого кадра на всех GPU. У ранее неподдерживаемых разноцветных
рамок нет прежнего корректного изображения для прямого сравнения времени.

## CPU и транспорт

Одинаковый synthetic frozen RenderFrame, 2048 рамок, 15 серий по 100 обновлений
и 5 серий прогрева. CPU sparse-position median: 2.04484 → 2.04713 мс;
sparse-paint: 2.01926 → 2.09547 мс. Это CPU backend, не GPU и не канонический
owned-delta workload. Результаты находятся в пределах наблюдаемого разброса;
абсолютное отсутствие CPU-регрессии данным измерением не доказывается.

Начальный транспорт совпал: 4 буфера, 4 записи, 270396 байт. No-op не меняет
версии, storage identity и ничего не загружает. Sparse uniform update сохраняет
одну запись 128 байт без order upload и GPU reallocations. Это не утверждение
об отсутствии всех JS-аллокаций.

Сырые серии и source hashes сохранены в соседних JSON. Проверки цветов,
прозрачности и независимых толщин выполняются настоящим GPU в
`webgpu/tests/multicolor-rounded-border.native.test.ts`.
