# WebGPU

`@zavx0z/immersive-webgpu` выполняет отрисовку Immersive и управляет ресурсами GPU:
шейдерами, buffers, textures, загрузкой данных и командами рисования.
Пакет связывает пространственные объекты Engine и display records Renderer
с их графическим представлением.

## Ответственность

- Подготовка и выполнение графических проходов для сцены и интерфейса.
- Создание, повторное использование и освобождение GPU-ресурсов.
- Загрузка текстур, изображений и поддерживаемого анимированного содержимого.
- Представление документа в пространственной плоскости и экранном overlay.
- Отрисовка Display напрямую или через растровую поверхность по действующему
  контракту плотности и проекции.

Семантическое дерево принадлежит DOM, стили и раскладка — Renderer,
пространственная математика и объекты — Engine. Browser владеет Canvas,
общим вводом и кадрами приложения. Проекции WebGPU используют результаты
этих владельцев и не подменяют документ собственным семантическим деревом.

## Публичный API

Вход `@zavx0z/immersive-webgpu` экспортирует `Renderer`, `RendererWebGpuBackend`,
`TextureLoader` и проекции `RendererWebGpuDocumentPlane`,
`RendererWebGpuDisplayPlane`, `RendererWebGpuScreenOverlay`.
Типы композиции описывают общий кадр, ограниченные виды и overlays.
Конкретные требования к ресурсам и их освобождению находятся в исходниках API.

Screen HUD использует позу, FOV и aspect единственного ViewPoint, но свой
clip range вокруг authored distance. Его слой получает собственные projection
uniform/frustum в том же Renderer и кадре; near/far Space не скрывают HUD ни при
приближении, ни при отдалении. UI viewport, hit testing и semantic Document
сохраняются. Дополнительный ViewPoint или Space не создаётся.

`TextureLoader.acquire` предоставляет lease источника; `load(device)` связывает
его с GPUDevice, `setVisible` управляет GIF, `release` завершает владение.
Неактивные записи ограничены 32 MiB и 128 entries; активные потребители не
вытесняются. Producer bitmap может сохраняться для непрозрачного источника и
других устройств; bitmap, декодированный из URL, закрывается после upload.
[Жизненный цикл изображений](scrolling.md#жизненный-цикл-изображений) описывает
handoff, отмену и границы измерения.

## Цвета сторон рамки

Rounded border поддерживает независимые RGBA и толщины сторон, включая
прозрачные и нулевые стороны. Внешний и внутренний контуры остаются общими;
цвет выбирается аналитически в одном quad, без дополнительных draw calls.
Соединения сторон смешивают premultiplied RGBA с антиалиасингом.

Одноцветный instanced record сохраняет 128 байт и не выделяет палитру.
Одноцветный pipeline исключает новую цветовую ветку через override константу.
Разноцветная рамка использует ленивую Float32-палитру по стабильному physical
slot; изменение цвета одной рамки обновляет 64 байта без перестановки order.
Scalar material использует прежний uniform slot 256 байт, размещая цвета
в неиспользуемом для rounded shader normal-matrix участке. Тесты
`multicolor-rounded-border` проверяют транспорт, повторное использование
буферов и пиксели настоящего GPU.

Shader линий получает коэффициент расстояния из материала Engine через
существующий per-object uniform. `distanceFade: 0` отключает attenuation RGB и
alpha; фиксированного мирового расстояния в shader нет. Это свойство не меняет
проход, depth-test или пространственное перекрытие объектов.

[`GlassMaterial`](../engine/src/material/glass-material.ts) описывает прозрачную
тонкую оболочку с поглощением и отражением света. Текущая реализация поддерживает
обычные Mesh с объединённой геометрией; ограничения оптического приближения,
порядок проходов и владение ресурсами описаны у [Renderer](src/renderer/index.ts).
Материал не создаёт collision body.

[Native GPU проверки](tests/glass-optics.native.test.ts) проверяют пиксели,
перекрытие, HUD и raster Display. [Короткий замер](../headless/fixtures/glass-performance.ts)
измеряет отрисовку объединённых боксов с ожиданием GPU; его результат не является
FPS браузерного приложения.
