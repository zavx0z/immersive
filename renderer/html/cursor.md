# Курсор элемента

HTML Renderer вычисляет наследуемый CSS `cursor` вместе с остальным стилем.
Поддерживаются ключевые слова из [типизированного контракта](src/cursor.ts),
включая направления resize, `grab`, `grabbing`, `pointer`, `text`, `none` и `auto`.
`inherit` и `unset` берут значение родителя; `initial` даёт `auto`. Значение по
умолчанию — `auto`. Custom properties и псевдосостояния участвуют в обычном cascade.
Невалидное статическое объявление не перекрывает предыдущего допустимого.
Пользовательские курсоры `url(...)` не входят в этот контракт.

Вычисленное значение публикуется в `HitMetadata.cursor` для того же элемента,
которому принадлежат hit, clips и transform. Изменение cursor не меняет геометрию.
Renderer не обращается к нативному Canvas. [Browser](../../browser/README.md)
выбирает актуальную проекцию и применяет значение к системному указателю.

[Проверки](tests/cursor.test.ts) описывают наследование, ключевые слова,
невалидные объявления, custom properties и hover без изменения размеров.
