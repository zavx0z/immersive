# Пространственное призматическое дерево

Публичный вход `@zavx0z/immersive-nodes/spatial/tree` принимает данные и содержимое
любого приложения. Он использует существующий Browser Root и не создаёт Document,
Canvas, Space, ViewPoint или отдельный цикл ввода.

`createSpatialTreeState` подготавливает store до монтажа `<SpatialTree source={state} />`.
`createSpatialTreeController` связывает его с существующим Root. `configure` получает
иерархию с размерами Display и callbacks выбора/фоновой загрузки. `ensureDisplay`
возвращает поверхность для интеграции приложения; `setContent` принимает публичное
готовое содержимое Component. Выбор сначала запрашивается callback, затем приложение
подтверждает его через `select`. Фоновая загрузка не меняет выбор и ViewPoint.

Числовая геометрия принадлежит [Prism Tree](../../layout/prism-tree/README.md).
Каждый родитель распределяет собственные дочерние поддеревья вокруг своего центра.
Размер их областей следует реальному составу и размерам потомков; общей матрицы
на весь уровень нет. Единственный ребёнок находится строго под родителем.
Каждому предмету соответствует один прямоугольник и одно тело. Тело вытянуто вниз
на одинаковую глубину, независимую от расстояния до следующего слоя, включая листья. От его нижнего торца
расходятся ветви к детям. Первый уровень с листом определяет пол: низ этого тела
находится на Z=0, более глубокие ветви продолжаются под полом. Сетка по умолчанию не отображается; `showGrid: true`
в параметрах контроллера включает её явно. Скрытая сетка не расширяет диапазон
глубины ViewPoint.

Размеры в `viewport` задаются в CSS px; отсутствие значения выбирает начальный
viewport просмотра. По умолчанию единый межслойный шаг равен 3 максимальным
сторонам Display, глубина всех тел — 1.05, зазор соседей — 0.24 той же стороны.
Размах ветвей не меняет шаг и глубину тел. `createSpatialTreeController({layout:
{layerGap, bodyDepth, spacing, aspectRatio}, ...})` принимает независимые настройки
алгоритма в мм; глубина тела должна быть положительна и меньше шага.
После конфигурации ширина и высота не меняются при resize и
движении ViewPoint. Общий ракурс наклонён и вписывает реальные углы тел вместо пустых углов общей AABB;
focus выбранного Display направлен сверху
и учитывает его aspect ratio. Fly не останавливается у плоскости родителя.

Неизменная числовая сцена индексируется отдельно от представления. Выборка видимых
тел ограничена 6000, Display — 256, подготовленного содержимого — 32. Приложение
освобождает исполнение до превышения последнего бюджета; просмотр не уничтожает
чужой контекст молча. Подготовленные и выбранный Display удерживаются при выходе
из viewport. Geometry revision меняется при конфигурации, а не при каждом кадре.
Это ограничивает отрисовку рабочего набора; постраничное хранение всего мирового
графа остаётся задачей источника данных.

Материалы принадлежат Space, проекция и ввод — Browser, геометрические операции
ViewPoint — Engine. Storybook не входит в зависимости компонента.

| CSS-переменная | Назначение |
| --- | --- |
| `--spatial-tree-family-1` … | Цвет корневой ветви и её потомков |
| `--spatial-tree-root-color` | Цвет общего корня |
| `--spatial-volume-appearance` | `holographic` либо `glass` |
| `--spatial-volume-opacity` | Прозрачность объёмов |
| `--spatial-volume-outline-opacity` | Прозрачность границ |
| `--spatial-volume-selected-opacity` | Прозрачность выделенного тела |
| `--spatial-volume-selected-outline-opacity` | Прозрачность выделенного контура |
| `--spatial-node-surface-opacity` | Прозрачность поверхности Frame |
| `--spatial-node-foreground` | Цвет текста |

Переменные наследуются от общего Space или передаются через branded `style`
компонента. HUD остаётся отдельной проекцией того же Root, не участвует в индексе
дерева и использует независимый диапазон глубины.

Дерево использует glass: тела `.10` с контурами `.40`, ветви `.025` с контурами `.10`,
выделенное тело `.18` с контуром `.90`. Это defaults общего SpatialVolumes;
унаследованные CSS-переменные имеют приоритет. Группы `spatial-tree-bodies` и
`spatial-tree-branches` позволяют адресовать оформление отдельно. Контуры сохраняют
проверку глубины, но не записывают её: прозрачная линия не вырезает следующие объёмы.
