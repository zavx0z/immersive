[Автоматический JSX protocol](index.ts) и его самостоятельные владельцы описаны в коде и контрактах.

Публичное авторство приложения задаёт `jsxImportSource: "@zavx0z/immersive/XReact"`.
Компилятор выдаёт imports из `XReact`, `XReact/compiled` и `XReact/slot` этого же
пакета; внутреннее авторство платформы сохраняет imports её самостоятельных owners.
Hooks и `memo` распознаются из публичного `XReact`, а `useFrame`, `useSpace` и
Canvas `createRoot` — из `XReact/browser`.

Сессия компилирует только свои `sourceRoots`. Внешний готовый компонент
подтверждается номинальным `CompiledComponent` в `.d.ts`; контракт слотов и
транзитивные декларации участвуют в кеше. Чтение декларации не разрешает
компиляцию исходников зависимости. Исполняемый JS компонента остаётся готовым
артефактом и использует общий runtime XReact.
