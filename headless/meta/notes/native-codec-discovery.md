# Обнаружение нативного кодека

Отложенная задача Headless: определять расположение библиотеки GdkPixbuf при
установке или запуске, без обязательной привязки к префиксу MacPorts.

Сейчас image-decoder.ts на macOS загружает библиотеку из /opt/local/lib,
на Linux используется системное имя libgdk_pixbuf-2.0.so.0. Перемещение Repo
этого не меняет; ограничение касается способа установки системной библиотеки.

Проверить загрузку при другом префиксе установки и понятную ошибку при отсутствии
кодека. Разрешённый путь остаётся локальной настройкой или вычисляемым значением,
не сохраняется как машинный адрес в исходниках потребителей. Реализацию пока
не менять; пользователь отложил эту работу 2026-10-06.
