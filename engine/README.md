# Движок

`@zavx0z/immersive-engine` предоставляет пространственную основу Immersive: объекты сцены,
геометрию, материалы, математику, анимацию, загрузку моделей и данные шрифтов.
Эти структуры используются для представления сцены и содержимого документа.

## Ответственность

- Преобразования и иерархия объектов, камеры ViewPoint и пространственные расчёты.
- Геометрия, meshes, линии, текст, материалы и источники света.
- Raycast, загрузка glTF и анимация.
- Данные шрифтов и геометрия текста.

Engine не выполняет WebGPU-рисование. WebGPU владеет конкретными GPU-ресурсами
и командами, Browser — Canvas, вводом и циклом кадров. В приложении объекты
Engine являются представлением содержимого общего Document.

Система координат правая: X вправо, Y вперёд, Z вверх. Единица расстояния —
миллиметр. Углы низкоуровневого Engine API задаются в радианах; авторский
контракт пространственных компонентов описан отдельно в пакете Space.

## Публичный API

Основной вход — `@zavx0z/immersive-engine`: `Object3D`, `ViewPoint`, геометрии, материалы,
объекты сцены и математические типы. `@zavx0z/immersive-engine/default-font` предоставляет
вход для стандартного шрифта, а `@zavx0z/immersive-engine/fonts/...` — опубликованные
файлы Inter и JetBrains Mono. Точный состав определяется `package.json#exports`.

## Раскладка и память текста

`Text` и `CachedText` принимают пятым аргументом необязательные
`{letterSpacing, spaceAdvance}`: первая геометрия строится сразу с этими значениями.
Прежний вызов из четырёх аргументов сохраняет `fontSize * 0.05` и `null`.
Обычный `Text` получает собственные изменяемые массивы; одинаковые `CachedText`
разделяют раскладку и геометрию, сохраняя собственный материал и преобразования.

Живой `CachedText` держит lease своей раскладки, в том числе когда скрыт clipping.
`updateGeometry()` переводит lease, `dispose()` освобождает её при окончательном
удалении узла. Повторный dispose безопасен; updateGeometry может снова получить
раскладку. GC освобождает забытый узел как страховка, а не замена lifecycle.
Нельзя продолжать рисовать освобождённую общую геометрию или передавать её
другому живому владельцу после завершения исходного потребителя.

Неактивные раскладки ограничены 16 MiB и LRU из 4096 записей; живые потребители
защищены даже при превышении лимитов. Бюджет включает четыре typed arrays и
верхнюю UTF-16 оценку ключа. `Text.getLayoutCacheStats()` отдельно показывает
active/inactive bytes, количество потребителей, arrayBytes и keyBytes.
Это учёт раскладок, а не полный JS heap, RSS или расход драйвера.

Рисующий владелец подписывается через `Text.onLayoutEvicted(listener)` и хранит
возвращённую отписку до своего dispose. Каждый callback получает вытесненные
stencil/cover geometry отдельно. Engine хранит слабые ссылки на callbacks;
глобальной очереди или сильной ссылки на забытый Renderer нет. Освобождение
конкретных GPU-ресурсов остаётся ответственностью WebGPU Renderer.

## Документация и проверки

Общий контракт изложен в TSDoc `src/index.ts`, детали — рядом с реализациями.
Проверки основного API, мировых матриц и системы координат находятся в `tests`.
Команда `bun run check` из директории пакета проверяет типы и выполняет тесты.

Состав рабочего пространства задаёт `package.json#workspaces`; контракт
пакета описывают этот README и публичные TSDoc.
